 Sistema de Manifestações e Ouvidoria (MySQL)

Projeto desenvolvido para a disciplina de **Criar e Modelar Banco de Dados Relacionais** da UNIFACISA, lecionada pelo Prof. Matheus Batista.

Sobre o Projeto
Este repositório contém a modelagem e implementação do banco de dados relacional para um **Sistema de Ouvidoria**, contemplando o cadastro de usuários (cidadãos, atendentes e administradores), setores, registro de manifestações, histórico de atendimentos, anexos e respostas.

Tecnologias Utilizadas
- **SGBD:** MySQL
- **Linguagem:** SQL (DDL e DML)

Estrutura de Scripts
- `schema_ddl.sql`: Criação do banco de dados, tabelas e restrições (Fase 2).
- `povoamento_dml.sql`: Inserção dos dados de teste solicitados.
- `consultas.sql`: Resolução das 5 consultas SQL do projeto.

Como Executar
1. Execute o script `schema_ddl.sql` no MySQL Workbench para criar o schema e a estrutura das tabelas.
2. Execute o script `povoamento_dml.sql` para popular as tabelas com os dados de teste.
3. Execute o script `consultas.sql` para visualizar os relatórios e resultados das agregações.
